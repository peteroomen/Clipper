# M13.5 — the Uni-Vibe

**Date:** 2026-08-10
**Branch:** `claude/tone-assistant-roadmap-b91w0s` (house convention would be
`feat/univibe`; this session's harness pins the branch name)
**Roadmap item:** M13.5 — Uni-Vibe. Also the named future consumer of `OptoCell`
(shipped with M13.3, docs §64 / ADR 025).

## Goal

Ship the Uni-Vibe as pedal type `vibe`, slot **12**, wired end to end (core, C
ABI, worklet, web face + assistant, native engine + APVTS + PedalCard), with a
hard, measured acceptance bar separating it from the Phase 90 already in the
lineup. Extract the **lamp** as its own component, per the instruction
`OptoCell.h` carries.

## Research channel — establish this FIRST, because it sets the rules

**Probed 2026-08-10, before any code:**

- `github.com` — reachable (code search works).
- `geofex.com` (R.G. Keen, "The Technology of the Univibe" — the canonical
  article) — **EGRESS_BLOCKED**.
- `montagar.com/~patj/univibe.txt` (parts list) — **EGRESS_BLOCKED**.
- No `.asc`, `.sch` or `.schx` Uni-Vibe netlist exists on GitHub (searched
  `univibe`/`uni-vibe` by extension and free text — 0 results).

So this is **the §57 / §61 situation, not the §63 one**: search-result extracts
only, no primary source, no netlist. **Every component value in this pedal is a
documented reconstruction** and §57's rule applies verbatim — *do not re-tune any
of them toward a sound; find the schematic.*

**One fact is SOURCED** and multiple independent extracts agree on it, which is
what makes the slice viable at all: the four phase-shift stages use
**staggered** capacitors — **0.015 µF, 0.22 µF, 470 pF, 0.0047 µF** — against a
conventional phaser's four matched values. Also sourced, and reported as such:
the sources state the reason for these *particular* values is not known. We model
the **stagger**, which is the structural fact; we do not invent a rationale.

**RULE ZERO (§63.14).** Three Uni-Vibe implementations exist on GitHub
(`clevelandmusicco/HothouseExamples`, `Generous-Corp/pulp`,
`rpowell5064/guitar-amp-mod`). They are **other people's models**. Nothing in
this slice is tuned toward, compared against, or copied from any of them.

## Approach

**Deliberate tone addition** (a new voice — it can move no golden by
construction, and if one moves that is a bug in the slice, not a bless).

### The acceptance bar: notch DISTRIBUTION, not "it sounds swirly"

The roadmap frames this as "four **mismatched** stages (not the Ninety's matched
four)". **That framing is wrong and the plan corrects it up front:**
`PhaserModel` already carries a deterministic **±1.5 %** per-stage detune,
specifically so its four notches do not stack into one null. So "mismatched" is
not the distinction — the *magnitude* is:

| | corner spread |
| --- | --- |
| Ninety (`PhaserModel`) | ±1.5 % — four corners essentially coincident, summing to the signature **two** moving notches |
| Uni-Vibe | 0.22 µF vs 470 pF = **~470:1** of capacitance — four corners across roughly nine octaves |

**The bar:** on an identical stimulus, measure the frequency of each notch in the
dry+wet sum and assert the **spread** (max/min notch frequency, in octaves)
differs between the two models by a large, hard-coded margin — the §57.4-shaped
"measurably not a re-skin" test, computed against the sibling rather than quoted.
Margin to be **recorded, not snugged**.

### The lamp is a new component, and `OptoCell` must NOT be widened

`OptoCell.h` names this slice and gives the instruction in terms: *"Do not grow
this class a `lightSourceKind` axis... a lamp's drive law is a different function
of a different quantity. Extract THAT if and when it arrives."* It has arrived.
So: a new `LampDrive` component (incandescent filament — thermal mass, so
brightness lags drive **asymmetrically**, rise ≠ fall), feeding four `OptoCell`s
held **by value**. `OptoCell` gets **zero** new parameters. If it turns out it
cannot be reused unwidened, that is a finding to report (ADR 023's procedure:
build the substitution and measure it), not a licence to add an axis.

**Second bar, and it is the one a JFET phaser cannot fake:** the lamp's thermal
lag makes the sweep **asymmetric in time** — the rise and fall of the notch
frequency have measurably different slopes at the same SPEED. `PhaserModel`'s
rounded-triangle LFO is symmetric by construction. Assert the asymmetry ratio,
and assert the Ninety's is ~1.0 on the same measurement.

### Modes, and the §62 trap

The real pedal has CHORUS (dry + wet) and VIBRATO (wet only). **§62 hit exactly
this and the lesson is written down:** forwarding a mode as a hard switch clicked
at **17.02×** the signal's own slew, and the fix was to never switch — vibrato is
the same dry/wet pair with the dry weight smoothed to zero. Do that here from the
first line rather than discovering it again.

Knobs: **SPEED / INTENSITY / MODE** (slots 0/1/2).

### Oversampling — decide by measurement, do not assume

The phaser precedent (§12) is linear-time-varying → no oversampling, latency 0.
But §61.7's gate declined OS *on measurement* after a first draft shipped it, and
§64 measured that a gain-cell multiply by an audio-rate signal genuinely needs
it. The photocell divider here is a multiply by a control signal. **Measure the
non-harmonic floor at 1×/2×/4×/8× and let the number decide**; a floor flat in
the factor means it is not aliasing (§54's tell), and a windowing check comes
first (§60's trap: a rectangular window's own sidelobe read as a −55.8 dB floor).

## What actually happened

**The branch is `feat/univibe`, cut from `de271df` (latest `main`).**

**The research channel was RE-PROBED and turned out to be narrower AND richer than
the plan expected.** Narrower: `geofex.com` and `montagar.com` still 403 at the
egress proxy, and this session's GitHub access is **repository-scoped**, so even
the code search §59/§63 leaned on was unavailable. Richer: search extracts yielded
**eight** sourced facts, not one — the four staggered caps (S1, with the sources'
own "the reason for these particular values is not known" attached), the lamp +
four LDRs in a reflective box (S2), transistor stages (S3), a phase-shift-oscillator
LFO (S4), the **equal-weight 100 kΩ / 100 kΩ mixer and what the CHORUS/VIBRATO
switch selects** (S5), the LDRs' **10 kΩ…100 kΩ illuminated range** (S6), the
**0.1–7.6 Hz** speed span (S7), and **INTENSITY as an LFO amplitude control into
the lamp driver** (S8). S6 + S8 together turned the lamp's bias and swing from a
choice into a **derivation**. Full table in docs §67.1. RULE ZERO held: none of
the three GitHub Uni-Vibe implementations was opened.

**The ROADMAP's framing was wrong and the slice corrected it up front**, exactly as
planned: `PhaserModel` already carries ±1.5 % per-stage detune, so "mismatched" is
not the distinction — the magnitude is (468:1 against 1.03:1, i.e. 8.87 octaves
against 0.043).

**`OptoCell` was reused UNWIDENED — zero new fields, zero new methods** — and the
lamp came out as its own header-only component (`LampDrive.h`), which is what
`OptoCell.h`'s banner instructed. The seam is `elExponent = 1.0`: the existing
published-source field with a degenerate exponent, so the quantity handed to the
cell IS the light and the source law lives in the lamp. ADR 026 records it, and
the header's stated *reason* turned out to be stronger than written — a lamp's
light is not a function of the drive at all, it is a function of a **state**
(measured: the same 0.66 V after different histories gives **21.43×** different
light).

**THE OVERSAMPLING MEASUREMENT OVERTURNED THE PRECEDENT, for a reason nobody
named in advance.** On *aliasing* the phaser precedent is right — the cells are lit
by an LFO under 8 Hz and nothing else, and the Hann-windowed floor is **flat**
across 1×/2×/4×/8× (2.63 dB of spread at −140 dB). But S1's 470 pF stage puts an
allpass corner at 14.6 kHz at the bias point and **33.9 kHz at the bright end**,
against and past Nyquist, and a bilinear allpass's phase warps there. Measured
against the analytic **analog** network at 44.1 kHz the upper notch lands
**+18.49 % out at 1× and +1.13 % at 4×**, against `PhaserModel`'s own pre-existing
**−3.10 %**. So the factor is DERIVED — 4× is the smallest house factor beating
the sibling's own error — and it ships at 4×, latency 72. That also closed a
rate dependence that would otherwise have needed an XFAIL (upper notch 15.9 % →
**0.599 %** across 44.1–96 kHz).

**Two things the plan asked to be decided by measurement rather than assumed, and
both came out against the tidy answer.** (1) **INTENSITY 0 is NOT bypass** — S8
makes it the lamp's LFO depth, so at zero the lamp still sits at its bias point
and the pedal is a **static comb** (27.56 dB of span). Asserted, not assumed.
(2) **The same `OptoCell` sits on the OPPOSITE side of ADR 006's scope rule here
from where it sits in `OptoModel`**: a Uni-Vibe's lamp is never off, so the cells
never rest at zero, and `VibeModel::maxAbsRestingState()` covers the four allpass
memories and nothing else.

**A bar that could not fail was found by the perturbation run and fixed** (§66's
lesson, found again): `testOptoCellIsUsedUnwidened` originally built its OWN
`OptoCell` with `elExponent = 1.0` and asserted on that, so perturbation P7 —
putting an EL exponent back on the vibe's cell — walked straight through it. A new
`VibeModel::cellCompositeExponent()` reads the shipped object; P7b is red on it.

**Found in passing and fixed:** `pedalMenuLabel()` had no `case PEDAL_OPTO`, so
M13.3's Lumen showed in the native gear tray and swap menu as the bare word
"Pedal" (docs §67.10).

## Measured results

**THE ACCEPTANCE BAR — notch distribution, both models, identical stimulus (48 kHz):**

| | lower notch | upper notch | spread | deepest |
| --- | --- | --- | --- | --- |
| Uni-Vibe | 102.51 Hz | 5463.14 Hz | **5.7359 oct** | −53.82 dB |
| Ninety (`PhaserModel`) | 832.07 Hz | 4685.87 Hz | **2.4935 oct** | −68.87 dB |
| | | | **contrast 3.2424 oct (2.300×)** | |

Bars `> 5.0` / `< 2.8` / contrast `> 2.5` / ratio `> 2.0` — margins RECORDED, not
snugged. Cap stagger **468.1 : 1 = 8.871 oct** against the Ninety's detune
**1.0305 : 1 = 0.0433 oct** (**204.9×**).

**Scale-free, measured over a 2.37× resistance excursion** (frozen LFO, four
phases): spread **5.7246 … 5.7809 oct**, range **0.0563**, against the analytic
analog **5.7249** at every point. So no reconstructed constant can reach the bar.

**THE SECOND BAR — sweep asymmetry (mean |d log2 fc/dt| rising vs falling):**

| SPEED | vibe rise | vibe fall | **vibe** | **ninety** | vibe depth | ninety depth |
| --- | --- | --- | --- | --- | --- | --- |
| 0.565 Hz | 3.868 oct/s | 3.303 | **1.1713** | 1.0008 | 3.152 oct | 3.321 |
| 1.344 Hz | 8.522 | 6.821 | **1.2494** | 1.0029 | 2.773 | 3.322 |
| 3.196 Hz | 14.763 | 10.693 | **1.3806** | 1.0015 | 1.955 | 3.321 |

**Attribution, two independent hooks** (1.344 Hz): shipped **1.3025** · lamp
instantaneous **1.0569** · cell memoryless **1.2385** · both removed **1.0015**.
The asymmetry is the **lamp's**. Third contrast, asserted: sweep depth
**3.281 → 0.959 oct** from SPEED 0.2 → 1.0, against the Ninety's **3.322 → 3.321**.

**The lamp derivation against the published cell range:** endpoints dim **0.318097 V**
/ bright **1.000000 V**; rendered excursion **10 001 … 99 462 Ω** against S6's
published 10 k…100 k.

**Oversampling:** floor **1× −140.41 / 2× −142.59 / 4× −143.05 / 8× −142.85 dB**
(spread 2.63 — flat, so not aliasing). Discretization error vs the analog network
at 44.1 kHz: **1× +18.49 % → 4× +1.13 %**, ninety **−3.10 %**. Shipped 4×,
latency **72 samples / 1.50 ms**, both pinned.

**INTENSITY 0:** chorus span **27.56 dB** (a real comb, not bypass); corner
movement **0.000e+00 octaves** at SPEED max; vibrato worst |gain| deviation
**0.0008 dB** (a pure allpass).

**Modes:** vibrato dry weight **exactly 0.0** (an `==`), chorus **0.5 / 0.5**;
CHORUS→VIBRATO landed mid-render over 16 step positions **0.95×** the signal's own
slew (§62 measured 17.02× for a forwarded hard switch).

**House battery:** ragged-block vs 128 **0.000e+00** · `reset()` vs fresh
**0.000e+00** · one NaN 11 899/12 000 → **0/12 000** after reset · resting state
**exactly 0** with the output at **exact digital silence** (lamp 2323.5 K, cell
11 765 Ω, trap 0.9805 — all real operating points, deliberately excluded) · rate
spread: notch spread **0.0085 oct**, lower notch **+0.010 %**, upper **+0.599 %** ·
DC on signal **−0.0104 %** clean, and a +0.1 V input offset **passes through**
(0.099968 V — linear network, no coupling caps, a named gap) · zipper SPEED
**0.53×**, INTENSITY **0.09×** · four cells agree **exactly** · envelope swing on a
chord **vibe 7.69 dB vs ninety 2.49 dB**.

**CPU: 12.86× realtime = 7.78 % of one 48 kHz stream** (the Ninety is 0.48 %, the
Lumen 3.67 %). Reported, not bounded. The cost is 4× oversampling times four
